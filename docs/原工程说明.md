# 三国守城 SanguoDefense

PICO Project Swan 上的桌面沙盘守城游戏：一张三国沙盘摆在玩家的桌子上，从托盘里捏起兵放到城墙、田边和路口，守住六场三国战役。设计方案见 `docs/选题方案_三国守城.md`（外层工程）。

> 2026-11-10 v0.2.1（versionCode 3）：11 个兵种和器械模型重新处理（修好接缝撕裂），赤壁的战船和拒马换成新的 3D 模型。详见 `更新说明.md`。

> 2026-11-09 v0.2（versionCode 2）：兵有了攻击动作（弓兵放箭、连弩三连发、枪兵突刺、投石车甩臂）；敌兵受击闪白后退，城门受撞震动、掉碎石、出现裂纹；六种计策都有专门的特效和声音；每场战役有自己的地形和天气（柳絮、扬尘、江雾、秋雨、落叶、大雪），旌旗随风。详见 `更新说明.md`。

> 2026-11-01 v0.1（versionCode 1），第一版完整内容，还没有在模拟器和真机上试过：
> - 六关：新野·初守、当阳桥、赤壁、樊城、西城·空城计、守荆州。每关 4～6 波敌军，每关一条三国故事和一种计策。
> - 我军五种兵：弓兵、枪兵、投石车、拒马、连弩（第三关起）。弓兵、投石车、连弩放城墙或田边；枪兵和拒马放在路上。每个兵最多升到 3 级，撤下退还六成粮草。
> - 敌军四种：步兵、骑兵、冲车（撞城门伤害大）、战船（从江上来，只有弓弩和投石车打得到）。敌兵被击退时化成一团烟，不表现伤亡。
> - 六种计策，计策条满了捏一下城楼上的将领就能用：火烧博望、据水断桥、借东风、水淹七军、空城计、八阵图。
> - 星级：守住城池；城门耐久剩一半以上；用粮不超过本关标准。
> - 操作：捏住托盘里的兵拖到发亮的空位上松开；捏一下已放好的兵可以升级或撤下；捏金色的「出战」开始下一波。沙盘自动找到真实桌面并摆在玩家正前方，菜单里可以重新摆正。
> - 场景里：关卡卡片、战况面板（粮草、波数、城门、计策条）、托盘说明、兵的升级面板、结果卡、菜单。两个窗口：军情图（选关、敌情、兵种）和战役志（每关的《三国演义》原文、白话和“史书怎么说”）。窗口一次只开一个，都有「关闭」。
> - 美术：沙盘、城墙、道路、江水在代码里搭建；诸葛亮、张飞、关羽、周瑜、四种兵和三种敌军是 Seedream 出图、Seed3D 生成的 Q 版模型。音效和音乐是 CC0（见 docs/素材来源.md）。
> - 自动测试 7 个：每关按预设布阵都能拿到 2 星以上；不布防必输；只用三分之一的布阵至少四关会输；拒绝的原因都会说明；撤下退款；樊城涨水；空城计开局就绪。`BalanceLab` 打印六关的平衡报告（模拟总时长约 23 分钟）。
> - 调试钩子 AutoPilot（logcat 标签 SanguoTest，只在 debug 包里）：`all` 按预设布阵依次打完六关（4 倍速）；还有 `level`、`place`、`up`、`wave`、`stratagem`、`speed`、`view`、`open`、`face`、`reset`。
> - 待验证：模拟器上的画面和自动通关；真机上捏起、拖动、放下的手感；桌面识别；模型在桌上的大小和朝向。

> 2026-11-02 模拟器验证通过（还没上真机）：
> - 六关在模拟器上全部守住：赤壁、空城计 3 星，其余 2 星；没有崩溃。
> - 模拟器上修好的三个问题：启动时崩溃（托盘的表在初始化之前就被用了）；城楼上的将领每帧被重设成 1 米高，挡住整个画面（现在缩放的是外层，模型本身的比例不动）；帧率低时一帧推进的战斗时间太长，樊城、荆州会输（现在每帧按不超过 50 毫秒分段推进，和平衡测试一致）。
> - 商店素材在 `商店素材/`：图标 1024×1024、海报 2560×1440、详情页 3 张 2560×1440。

> 2026-11-10 模拟器验证（v0.2）：新野一关自动守住（4 倍速，2 星，和 v0.1 相同），地形、田地、村舍、旌旗都显示正常，没有闪退。

## 构建

```
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

安装包复制在 `apk/`：`SanguoDefense-debug.apk`（带调试钩子）和 `SanguoDefense-release.apk`（正式签名）。
